# quempin.cl — sitio estático

8 páginas: `index.html` (Propuesta Industrial), `servicios.html`, `sectores.html`, `peru.html`, `hidrogeno-verde.html`, `clientes.html`, `nosotros.html`, `descargables.html`.

## Publicar con GitHub Pages
1. Sube TODO el contenido de esta carpeta a la raíz del repositorio (incluye el archivo oculto `.nojekyll` y la carpeta `assets/`).
2. Settings → Pages → Deploy from branch → rama `main`, carpeta `/ (root)` → Save.
3. El sitio queda disponible en `https://<usuario>.github.io/<repo>/` en 1-2 minutos.
